## 5. 앱 콘텐츠 설문 답변

- **개인정보처리방침**: 위 URL
- **광고**: 광고 없음
- **앱 액세스 권한**: 모든 기능을 로그인 없이 사용 가능
- **콘텐츠 등급 설문**: 폭력·선정성·도박·약물 등 모두 "아니요" → 전체이용가 예상
- **타겟층**: 18세 이상 (아동 대상 앱으로 설정하면 추가 심사가 필요하므로)
- **데이터 보안(Data safety)**:

  - (기기 안에만 저장되고 개발자에게 전송되지 않는 데이터는 '수집'에 해당하지 않음)
- **정부 앱 / 금융 기능 / 건강 앱**: 해당 없음

## 6. 남은 순서

1. **[본인] 개발자 가입** — play.google.com/console, 등록비 약 25달러(1회), 본인 인증 (며칠 걸림)
2. **[함께] 앱 파일 만들기** — pwabuilder.com 에 `https://hyemin-ai.github.io/Gangnam-beauty/prayer/` 입력 → Android → 패키지 이름 `io.github.hyemin_ai.mantra`
   - 함께 받는 **서명 키(signing key) 파일과 비밀번호는 절대 잃어버리지 말 것** (잃으면 업데이트 불가)
3. **[Claude] 주소창 없애기 설정** — Play Console의 '앱 서명 키 SHA-256 지문'을 알려주면,
   `hyemin-ai.github.io` 저장소에 `.well-known/assetlinks.json` 을 만들어 앱 위의 주소창이 보이지 않게 함
4. **[본인] 비공개 테스트** — 안드로이드를 쓰는 지인 **12명 이상**이 테스트 링크로 설치해 **14일 연속** 유지
   (이미 링크를 받은 지인 20명 중 안드로이드 사용자에게 부탁하면 됨. 아이폰 사용자는 참여 불가)
5. **[본인] 프로덕션 출시 신청** → 심사 (보통 며칠)

※ 등록비·테스터 수·기간 등 정책은 바뀔 수 있으니 Play Console 안내를 기준으로 확인하세요.
