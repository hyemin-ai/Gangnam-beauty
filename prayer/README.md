# 합장 — 염주·목탁·싱잉볼 기도 앱 (웹앱 1차 버전)

휴대폰 하나로 염주, 목탁, 싱잉볼 기도를 하는 흑백 웹앱(PWA)입니다. 앱스토어 없이 인터넷 주소로 배포하고, 휴대폰 **홈 화면에 추가**하면 일반 앱처럼 쓸 수 있습니다. 비용은 0원입니다.

## 들어 있는 기능

| 탭 | 기능 |
|---|---|
| 염주 | 맨 위에 **나의 소원**이 항상 떠 있습니다(눌러서 수정). 화면 어디든 누르면 나무 구슬이 한 알씩 돌며 짧게 '딸깍' 소리가 납니다. 21개/108개를 고를 수 있고 각각 따로 셉니다. 한 바퀴를 돌면 싱잉볼 소리와 진동이 오고 바퀴 수가 기록됩니다(오늘 몇 바퀴인지도 표시). 앱을 껐다 켜도 숫자가 유지됩니다. 초기화는 길게 누를 때만 됩니다. |
| 목탁 | 누르면 목탁 소리와 짧은 진동이 옵니다. |
| 싱잉볼 | 누르면 싱잉볼 소리가 납니다. 5/15/30분 간격 타이머가 있고, 화면이 꺼져도 울립니다. |
| 사찰 | 절 이름으로 카카오맵 검색, 자주 가는 절 1·2·3순위 지정, 방문 기록(절 이름·날짜·소원) 작성·수정·삭제 |
| 설정(⚙) | 소리·딸깍 소리·진동 켜기/끄기, 기록 백업 파일 저장·불러오기 |

## 무료로 인터넷에 올리기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**로 갑니다.
2. Source를 `Deploy from a branch`로, 브랜치와 폴더(`/ (root)`)를 고르고 Save를 누릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/prayer/` 주소로 열립니다.
4. 휴대폰에서 이 주소를 열고 홈 화면에 추가합니다.
   - 아이폰: Safari 공유 버튼 → **홈 화면에 추가**
   - 안드로이드: Chrome 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

> 앱 파일을 고친 뒤에는 `sw.js` 맨 위의 `VERSION` 값을 `'v2'`, `'v3'`처럼 올려야 이미 설치한 휴대폰에도 새 버전이 적용됩니다.

## 파일 구성

```
prayer/
├─ index.html            화면 구조
├─ style.css             디자인 (흑백, 다크 모드 자동)
├─ app.js                모든 동작
├─ sw.js                 오프라인 동작용 (서비스 워커)
├─ manifest.webmanifest  앱 이름·아이콘
├─ icons/                앱 아이콘
├─ sounds/               목탁·싱잉볼 소리 + 타이머용 5/15/30분 파일
└─ tools/                소리·아이콘을 만드는 파이썬 스크립트
```

## 화면과 배터리

- 항상 **검정 배경에 흰 글씨**입니다. 순수 검정(#000)은 요즘 휴대폰(OLED 화면)에서 거의 전기를 쓰지 않습니다.
- 소리가 끝나고 조용해지면 오디오 엔진을 잠재우고, 화면이 꺼져 있을 때는 타이머 숫자 계산도 멈춥니다.
- 앱 전체 크기는 타이머용 긴 소리를 빼면 약 0.6MB입니다.

## 진짜 녹음·사진으로 바꾸기

지금 들어 있는 소리와 구슬 그림은 **직접 만든 것**이라 저작권 문제가 없습니다. 실제 녹음이나 사진으로 바꾸고 싶으면 아래처럼 하세요.

1. 자유롭게 써도 되는 파일을 구합니다. 가장 좋은 건 **직접 녹음하거나 찍은 것**입니다.
   - 소리: Pixabay 효과음(pixabay.com/sound-effects, "singing bowl", "wood block"), Freesound(CC0만)
   - 사진: Pixabay, Unsplash (구슬 하나가 사진 한가운데 꽉 차게 찍힌 것)
   - ⚠️ YouTube 영상 소리는 대부분 저작권이 있어 쓸 수 없습니다.
2. GitHub 저장소에서 **Add file → Upload files**로 아래 이름에 맞춰 올립니다.

| 바꿀 것 | 올릴 위치와 이름 |
|---|---|
| 싱잉볼 소리 (타이머 포함) | `prayer/sounds/src/bowl.mp3` (.wav .flac .ogg도 가능) |
| 목탁 소리 | `prayer/sounds/src/moktak.mp3` |
| 염주 딸깍 소리 | `prayer/sounds/src/click.mp3` |
| 구슬 사진 | `prayer/images/src/bead.jpg` |
| 모주(큰 구슬) 사진 | `prayer/images/src/head.jpg` |

3. Claude에게 "올린 파일로 소리/사진 바꿔줘"라고 하면 `tools/make_sounds.py`, `tools/make_beads.py`를 다시 실행해 앞뒤 무음 자르기, 음량 맞추기, 동그랗게 자르기까지 해서 적용합니다.

## 소리는 어떻게 만들었나

`tools/make_sounds.py`가 실제 악기가 떨리는 방식(싱잉볼의 비조화 배음과 맥놀이, 목탁 나무통의 공명, 채가 닿는 순간, 방 울림)을 흉내 내어 **코드로 합성**합니다. `tools/make_beads.py`는 나뭇결과 광택이 있는 구슬을 3D로 계산해 그립니다.

```bash
pip install numpy pillow lameenc miniaudio
python3 prayer/tools/make_sounds.py
python3 prayer/tools/make_beads.py
```

### 싱잉볼 타이머가 화면이 꺼져도 울리는 원리

브라우저는 화면이 꺼지면 코드 타이머를 멈춥니다. 대신 **"싱잉볼 한 번 + 무음"으로 정확히 5분/15분/30분 길이인 소리 파일**(`sounds/bowl-5m.mp3` 등)을 만들어 두고 **반복 재생**합니다. 음악이 재생 중이면 휴대폰은 화면이 꺼져도 소리를 계속 내 주기 때문에, 파일이 한 바퀴 돌 때마다 종이 울립니다.

한계:
- 다른 앱에서 음악이나 동영상을 틀거나 전화가 오면 멈춥니다. 앱 화면에 "멈췄습니다"가 표시됩니다.
- 30분 파일은 약 9MB라서 처음 한 번은 인터넷으로 받아야 합니다. 그 뒤에는 휴대폰에 저장됩니다.
- 기기마다 다를 수 있으니 **실제 휴대폰에서 화면을 끄고 15분 이상** 꼭 시험해 보세요.

## 알려진 한계

- **아이폰은 진동이 제한적입니다.** 웹앱에서는 진동 기능을 쓸 수 없어서, iOS 18 이상에서만 되는 우회 방법(숨은 스위치의 시스템 햅틱)을 넣었습니다. 안 되면 소리만 납니다. 안드로이드는 정상적으로 진동합니다.
- 아이폰 **무음 스위치**가 켜져 있으면 소리가 안 날 수 있습니다. (iOS 17 이상은 대부분 소리가 납니다.)
- 모든 기록은 **이 휴대폰의 브라우저에만** 저장됩니다. 브라우저 데이터를 지우면 사라지니 설정 → **백업 파일 저장**을 가끔 해 두세요.
- 사찰 탭은 지금 카카오맵 **검색 링크**만 씁니다(API 키 필요 없음). 전국 사찰 목록은 다음 단계에서 공공데이터포털의 전통사찰 데이터를 넣을 예정입니다.
